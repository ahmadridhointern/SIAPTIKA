# Coding Rules

Selalu gunakan Laravel Best Practice.

## Arsitektur

Gunakan MVC.

Gunakan Eloquent ORM.

Gunakan Form Request Validation.

Gunakan Resource Controller.

Gunakan Route Group.

Gunakan Middleware.

Gunakan Dependency Injection jika diperlukan.

---

## Kode

Ikuti prinsip:

SOLID

DRY

KISS

Clean Code

Readable Code

---

## Database

Gunakan Migration.

Gunakan Seeder.

Gunakan Factory jika diperlukan.

---

## UI

Gunakan Blade.

Gunakan Tailwind CSS.

Gunakan Layout yang reusable.

Gunakan Blade Components.

---

## Penamaan

Controller

ActivityController

Model

Activity

View

activities/index.blade.php

Route

activities.index

Gunakan nama yang konsisten.

---

## Validasi

Semua form menggunakan Form Request.

Jangan melakukan validasi langsung di Controller.

---

## Security

Password menggunakan Hash.

Gunakan CSRF.

Gunakan Middleware.

Gunakan Authorization jika diperlukan.

---

## Performance

Hindari N+1 Query.

Gunakan eager loading.

Optimalkan query.

---

## Responsif

Desktop

Tablet

Mobile

Seluruh halaman harus responsif.

---

## Bahasa

Seluruh UI menggunakan Bahasa Indonesia.
