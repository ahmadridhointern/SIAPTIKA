## 1. Mengenal Aplikasi SIAPTIKA

**SIAPTIKA** adalah aplikasi komputer (desktop Windows) yang dirancang khusus untuk mencatat, mengelola jadwal agenda, serta mengarsipkan dokumen resmi kedinasan pada Bidang Aplikasi Informatika (APTIKA) Dinas Komunikasi, Informatika, dan Statistik Provinsi Riau secara rapi, cepat, dan terpusat.

Untuk memberikan kemudahan bagi seluruh staf di kantor, SIAPTIKA hadir dalam **2 (dua) varian aplikasi**:

```
+-----------------------------------------------------------------------------------+
|                              PILIHAN APLIKASI SIAPTIKA                            |
+-----------------------------------------------------------------------------------+
| 1. SIAPTIKA Dashboard (Untuk Seluruh Pegawai)                                     |
|    - Digunakan oleh seluruh staf dan pegawai Bidang APTIKA.                       |
|    - Berfungsi untuk memantau agenda rapat hari ini dan kegiatan mendatang.       |
|    - Berfungsi untuk membaca dan mengunduh berkas arsip naskah dinas.             |
|    - SANGAT MUDAH: Buka aplikasi dan langsung gunakan tanpa perlu login!          |
+-----------------------------------------------------------------------------------+
| 2. SIAPTIKA Administrator (Khusus Pengelola / Staf Arsip)                         |
|    - Digunakan oleh Staf Administrasi / Pengelola Arsip Kedinasan.                |
|    - Berfungsi untuk mencatat agenda baru, memperbarui jadwal, dan mengunggah     |
|      arsip (surat tugas, notulen rapat, dokumentasi foto).                        |
|    - Memerlukan ID Pengguna resmi: ADM001 beserta kata sandi dinas.               |
+-----------------------------------------------------------------------------------+
```

---

## 2. Kebutuhan Komputer

Aplikasi SIAPTIKA sangat ringan dan tidak membebani komputer kerja Anda. Berikut syarat minimalnya:

* **Sistem Operasi**: Windows 10 atau Windows 11 (versi 64-bit).
* **Komputer / Laptop**: Prosesor Intel atau AMD (Dual-Core 1.6 GHz ke atas).
* **Memori (RAM)**: Minimal 4 GB (disarankan 8 GB).
* **Ruang Hard Disk**: Ruang kosong minimal 500 MB.
* **Koneksi Internet**: Diperlukan koneksi internet (Wi-Fi kantor atau kabel LAN) untuk memperbarui data agenda dan membuka dokumen arsip di penyimpanan awan (*cloud*).
* **Bebas Ribet**: Anda **TIDAK PERLU** menginstal software server tambahan (seperti XAMPP, PHP, atau database terpisah) karena seluruh mesin aplikasi sudah menyatu di dalamnya (*self-contained*).

## 3. Cara Memasang Aplikasi (Instalasi)

Pemasangan aplikasi hanya dilakukan **satu kali** di setiap komputer kerja:

1. **Pilih Berkas Pemasang (*Installer*)** sesuai peran Anda:
   * Untuk Pegawai Umum: Pilih `SIAPTIKA Dashboard Setup 1.0.0.exe`
   * Untuk Pengelola Admin: Pilih `SIAPTIKA Administrator Setup 1.0.0.exe`
2. **Klik Dua Kali (*Double-Click*)** pada berkas tersebut.
3. Jendela instalasi akan muncul. Ikuti langkah sederhana berikut:
   * Klik tombol **Next (Lanjut)**.
   * Biarkan lokasi penyimpanan pada pengaturan default.
   * Pastikan kotak pilihan **Create a desktop shortcut** tercentang (agar ikon aplikasi otomatis muncul di layar utama komputer).
   * Klik **Install** dan tunggu proses berjalan selama sekitar 15–30 detik.
   * Klik **Finish (Selesai)**.
4. Ikon pintasan **SIAPTIKA** kini telah siap digunakan di layar Desktop komputer Anda.

## 4. Panduan untuk Seluruh Pegawai (SIAPTIKA Dashboard)

Varian ini dibuat agar seluruh pegawai dapat melihat informasi agenda kantor tanpa kesulitan teknis.

### A. Membuka Aplikasi
1. Klik dua kali ikon **SIAPTIKA Dashboard** pada layar Desktop.
2. Tunggu 2–3 detik. Aplikasi akan langsung membuka halaman utama **Portal Dashboard Pegawai**.
3. Pegawai **TIDAK PERLU LOGIN** (tidak memerlukan username atau password).

(Peletakan Gambar Tampilan Dashboard Pegawai)  
[TEMPAT GAMBAR: Desain Antarmuka Portal Dashboard Pegawai.png]

---

### B. Membaca Informasi Jadwal
Pada layar utama, pegawai dapat melihat:
1. **4 Kartu Informasi Cepat** di bagian atas:
   * *Total Kegiatan Terdaftar*
   * *Kegiatan Hari Ini*
   * *Kegiatan Mendatang*
   * *Kegiatan Telah Selesai*
2. **Tabel Agenda Hari Ini**: Menampilkan seluruh kegiatan yang sedang atau akan berlangsung pada hari ini, lengkap dengan jam dan lokasi ruangan rapat.
3. **Tabel Agenda Mendatang**: Menampilkan jadwal agenda kedinasan untuk hari-hari berikutnya agar pegawai dapat mempersiapkan diri lebih awal.

---

### C. Mencari dan Menyaring Kegiatan
* **Pencarian Cepat**: Ketik kata kunci (misalnya nama rapat seperti *"SPBE"* atau nama tempat seperti *"Ruang Melati"*) pada kotak pencarian di atas tabel. Daftar kegiatan akan tersaring secara instan.
* **Pilihan Status**: Klik menu pilihan status (*Filter*) jika hanya ingin melihat kegiatan yang berstatus *Terjadwal*, *Sedang Berlangsung*, atau *Selesai*.

---

### D. Melihat Rincian & Mengunduh Dokumen Arsip
1. Klik pada salah satu baris kegiatan yang ingin dilihat.
2. Jendela **Rincian Kegiatan** akan terbuka, menampilkan deskripsi agenda dan daftar berkas arsip resmi yang sudah diunggah oleh bagian administrasi.
3. **Membaca Dokumen Langsung (Pratinjau)**:
   * Klik tombol **Pratinjau / Lihat** pada berkas (Surat Tugas, Notulen, atau Foto).
   * Berkas PDF atau gambar akan langsung terbuka di layar tanpa perlu aplikasi lain.
4. **Menyimpan Salinan Berkas (Unduh)**:
   * Klik tombol **Unduh**. Berkas resmi akan langsung tersimpan di folder *Downloads* komputer Anda.

> **Tips Kenyamanan**: Seluruh fitur pada portal pegawai bersifat *read-only* (hanya baca). Pegawai tidak perlu khawatir akan salah menghapus atau merusak data dinas karena tombol hapus dan ubah dinonaktifkan secara otomatis.

## 5. Panduan untuk Administrator (SIAPTIKA Administrator)

Varian ini diperuntukkan bagi Staf Tata Usaha / Arsiparis yang bertugas mengelola data kegiatan dan dokumen dinas.

### A. Masuk ke Aplikasi (Login)
1. Klik dua kali ikon **SIAPTIKA Administrator** pada Desktop.
2. Layar akan menampilkan **Formulir Masuk Administrator**.
3. Masukkan data kredensial resmi:
   * **ID Administrator**: `ADM001` (gunakan huruf kapital)
   * **Kata Sandi**: *(masukkan kata sandi kedinasan yang telah ditentukan)*
4. Klik tombol **Masuk**. Jika benar, Anda akan diarahkan ke Dashboard Pengelola.

(Peletakan Gambar Tampilan Login Administrator)

### B. Mengelola Data Kegiatan Dinas
Pilih menu **Kegiatan** pada bilah navigasi atas untuk membuka daftar tabel kegiatan.

(Peletakan Gambar Dashboard Utama Administrator)  
[TEMPAT GAMBAR: Desain Antarmuka Dashboard Utama Administrator.png]

#### 1. Menambah Jadwal Kegiatan Baru
1. Klik tombol **+ Tambah Kegiatan** di kanan atas.
2. Formulir pengisian data akan muncul:
   * **Judul Kegiatan**: Tuliskan nama acara atau agenda dinas (contoh: *Bimtek Pemanfaatan Aplikasi SPBE*).
   * **Tanggal**: Tentukan tanggal acara pada kalender.
   * **Waktu**: Tentukan jam mulai acara (contoh: *09:00 WIB*).
   * **Tempat**: Tuliskan tempat rapat (contoh: *Ruang Rapat Diskominfotik Riau Lt. 2*).
   * **Status**: Kolom status **tidak perlu diisi** karena akan otomatis terisi oleh sistem sesuai dengan tanggal dan waktu pelaksanaan kegiatan (*Terjadwal* atau *Selesai*).
   * **Deskripsi**: Tuliskan ringkasan pokok pembahasan rapat (opsional).
3. Klik tombol **Simpan Kegiatan**. Agenda baru akan langsung tersimpan ke server dan seketika muncul di aplikasi seluruh pegawai.

#### 2. Memperbarui / Mengubah Jadwal Kegiatan
1. Pada tabel kegiatan, klik ikon **Ubah (Ikon Pensil)** pada kegiatan yang ingin diperbaiki.
2. Perbarui data yang diperlukan (misalnya perubahan jam atau ruangan).
3. Klik **Perbarui Kegiatan**.
4. *Aturan Khusus*: Kegiatan yang tanggalnya telah lewat atau telah berstatus selesai tidak dapat diubah kembali demi menjaga integritas data riwayat dinas.

#### 3. Menghapus Jadwal Kegiatan
1. Klik ikon **Hapus (Ikon Tempat Sampah)** pada baris kegiatan yang salah input.
2. Konfirmasi pilihan Anda saat kotak dialog muncul.
3. *Aturan Keamanan*: Kegiatan yang **sudah memiliki berkas dokumen arsip tidak dapat dihapus**. Hapus terlebih dahulu berkas arsip di dalamnya jika kegiatan tersebut benar-benar ingin dibatalkan.

---

### C. Mengelola dan Mengunggah Dokumen Arsip
Setiap kegiatan yang diselenggarakan dapat dilengkapi dengan dokumen naskah dinas resmi.

#### 1. Mengunggah Berkas Baru
1. Klik judul kegiatan pada tabel untuk membuka halaman **Rincian Kegiatan & Berkas Arsip**.
2. Pada bagian bawah, klik tombol **+ Unggah Dokumen**.
3. Pilih **Jenis Dokumen**:
   * *Surat / Dokumen*
   * *Notulen*
   * *Dokumentasi*
4. Klik tombol **Pilih Berkas (Browse)** dan pilih file dari komputer Anda:
   * Format yang didukung: **PDF, DOC, DOCX, JPG, JPEG, PNG, MP4**.
   * Batas ukuran: Maksimal **10 MB per berkas**.
5. Klik **Unggah Dokumen**. Berkas akan otomatis tersimpan aman di server awan (*cloud storage*).

#### 2. Mengganti Berkas yang Salah
Jika berkas yang diunggah salah atau ada revisi notulen:
1. Klik ikon **pensil** pada baris dokumen terkait.
2. Pilih berkas baru dari komputer, lalu klik **Simpan Perubahan**. Sistem akan secara otomatis menghapus berkas lama dan menggantikannya dengan berkas yang baru.

#### 3. Pratinjau dan Unduh Berkas
* Klik ikon **Pratinjau** untuk membaca naskah dokumen langsung di jendela aplikasi.
* Klik ikon **Unduh** untuk mengunduh dokumen fisik ke komputer kerja.

---

### D. Keluar dari Aplikasi (Logout)
Bila telah selesai melakukan pembaruan data:
* Klik ikon **Logout (Keluar)** di sudut kanan atas layar. Sesi login akan ditutup dengan aman sehingga komputer tidak disalahgunakan pihak lain.

## 6. Tanya Jawab & Solusi Cepat (Troubleshooting)

Berikut adalah panduan solusi praktis jika Anda menemui kendala saat menggunakan aplikasi:

| Kendala yang Terjadi | Kemungkinan Penyebab | Langkah Solusi Praktis |
| :--- | :--- | :--- |
| **Aplikasi tidak terbuka atau langsung tertutup setelah diklik** | Terdapat proses aplikasi lama yang belum tertutup sempurna di latar belakang. | 1. Tekan tombol `Ctrl + Shift + Esc` di keyboard untuk membuka *Task Manager*.<br>2. Cari nama `SIAPTIKA Administrator` atau `SIAPTIKA Dashboard`.<br>3. Klik kanan dan pilih **End Task**.<br>4. Buka kembali aplikasi seperti biasa. |
| **Sistem tidak mau terbuka atau muncul pesan *Internal Server Error*** | Layanan basis data (Supabase) berada dalam status dijeda (*paused*) otomatis karena tidak ada aktivitas atau penggunaan selama 14 hari. | Buka kembali dasbor [Supabase](https://supabase.com/dashboard) melalui peramban web (*browser*), pilih proyek basis data SIAPTIKA, lalu klik tombol **Restore Project** / **Resume Project** agar proyek berjalan aktif kembali (*running*). |
| **Muncul pesan "Gagal terhubung ke server/database"** | Komputer tidak terhubung ke jaringan internet kantor. | Pastikan kabel LAN terpasang atau Wi-Fi kantor terhubung aktif, karena data tersimpan secara terpusat di server awan (*cloud*). |
| **Gagal mengunggah berkas dokumen arsip** | Ukuran file melebihi 10 MB atau koneksi internet terputus di tengah jalan. | 1. Periksa ukuran file Anda (pastikan di bawah 10 MB).<br>2. Jika file PDF terlalu besar, perkecil (*compress*) terlebih dahulu.<br>3. Pastikan koneksi internet stabil lalu coba unggah ulang. |
| **Gagal masuk / Password salah terus-menerus** | Salah mengetik ID atau tombol Caps Lock menyala. | 1. Pastikan kolom ID diisi persis: `ADM001` (huruf kapital).<br>2. Periksa apakah lampu **Caps Lock** di keyboard Anda menyala saat mengetik kata sandi. |
| **Tombol Ubah atau Hapus tidak berfungsi** | Pembatasan aturan kedinasan pada sistem. | - Kegiatan yang sudah lewat tidak dapat diubah.<br>- Kegiatan yang memiliki dokumen arsip tidak dapat dihapus sebelum dokumennya dikeluarkan. |
